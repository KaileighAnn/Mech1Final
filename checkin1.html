Check-In Overview

Since completing my project proposal, I have finished all of the CAD work, completed the laser cutting, and assembled the mechanical components of my automatic dog feeder. I have also started developing and testing the Arduino code that will control the sliding gate mechanism.

Mechanical Design Progress

I completed the design of all mechanical components in SolidWorks. Each component was modeled individually before being combined into a complete assembly to check the fit and placement of the parts.

Base and Side Supports

The base was designed around my dog's 8-inch food bowl. The side panels use interlocking tabs and slots to support the upper portion of the feeder.

Food Slide and Storage Container

I designed a sloped food slide with raised edges to guide the food into the bowl. The food storage container tapers toward the bottom to direct food toward the sliding gate.

Lid and Food Holder Support

I designed a removable lid for refilling the food container and a laser-cut top support to hold the container in place. The lid also provides an area for mounting the Arduino.

Sliding Gate Mechanism

I sourced an existing rack-and-pinion gate mechanism and modified it in SolidWorks to fit the opening of my food storage container. The servo motor rotates the pinion gear, causing the gate to slide open and closed.

Arduino Programming Progress

I have started developing and testing the Arduino code that controls the servo motor. The current code uses a push button to open and close the sliding gate.

When the button is pressed, the servo rotates from 0 degrees to 180 degrees to open the gate. When the same button is pressed again, the servo returns to 0 degrees to close the gate.

Current Arduino Code

#include <Servo.h>

Servo gateServo;

const int servoPin = 9;
const int buttonPin = 2;

const int closedPosition = 0;
const int openPosition = 180;

bool gateOpen = false;
int lastButtonState = HIGH;

void setup() {
  gateServo.attach(servoPin);
  pinMode(buttonPin, INPUT_PULLUP);

  gateServo.write(closedPosition);
}

void loop() {
  int buttonState = digitalRead(buttonPin);

  if (buttonState == LOW && lastButtonState == HIGH) {

    gateOpen = !gateOpen;

    if (gateOpen) {
      gateServo.write(openPosition);
    } else {
      gateServo.write(closedPosition);
    }

    delay(50);
  }

  lastButtonState = buttonState;
}

Pin Connections

  • Pin 9: Servo motor signal
  • Pin 2: Push button
  • 5V: Servo power for initial testing
  • GND: Common ground

Challenges and Design Considerations

Component Fit: Making sure the laser-cut and 3D-printed components fit together properly.

Gate Clearance: Providing enough clearance for the sliding gate to move freely.

Servo Speed: Adjusting the Arduino code to create a slower and more controlled movement.

Food Jamming: Making sure the dog food can travel through the gate and chute without becoming stuck.

Power Supply: Determining how to power the Arduino without keeping it connected to my computer.
